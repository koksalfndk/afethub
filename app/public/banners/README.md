# Banner görselleri

Ana sayfadaki bilgilendirici slider bu klasördeki dosyaları kullanır:

- `wildfire.jpg` — afet bildirimi slaytı
- `coordination.jpg` — doğrulama / koordinasyon slaytı
- `volunteers.jpg` — kurumlar ve gönüllüler slaytı

Öneriler: 1600×900 veya daha geniş, yatay, sağ tarafı görsel olarak yoğun (sol
üçte biri metin panelinin altında kalır), WebP/JPG, dosya başına 200 KB altı.

Dosya yoksa slayt sakin bir gradyana düşer; arayüz bozulmaz. Kural 04 gereği
operasyonel ekranlarda dramatik afet fotoğrafı kullanılmaz — bu banner tek
istisnadır, o yüzden görselleri sakin ve insan onurunu zedelemeyen kareler
arasından seçin. Telif hakkı uygun olmayan görsel eklemeyin.
